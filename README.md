## 사용법

```
https://cdn.jsdelivr.net/gh/haehyun0409-design/donbora-assets@main/detail/fullcare/pc_01.webp
```

## 구조

```
detail/{상품}/pc_NN.webp   PC 2400px 폭
detail/{상품}/mo_NN.webp   모바일 1125px 폭
detail/{상품}/*.jpg        구형 브라우저 폴백
```
